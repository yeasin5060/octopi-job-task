# SaaS Organization & Subscription Management Platform

একটি পূর্ণাঙ্গ SaaS Management Platform, যেখানে Organization, User, Subscription Plan, Payment, Transaction এবং Platform Administration পরিচালনা করা যায়।

এই project-টি MERN Stack ব্যবহার করে তৈরি করা হয়েছে এবং Stripe Payment Integration-এর মাধ্যমে subscription payment পরিচালনা করা হয়েছে।

---

## 🚀 Project সম্পর্কে

এই platform-এর মাধ্যমে বিভিন্ন Organization তাদের subscription plan নির্বাচন করে payment করতে পারবে এবং নিজেদের organization পরিচালনা করতে পারবে।

অন্যদিকে Platform Admin পুরো SaaS platform পরিচালনা করতে পারবে।

Platform Admin দেখতে পারবে:

- মোট Organization
- মোট User
- Active Subscription
- Total Revenue
- Failed Payment
- সকল Transaction
- Recent Organization
